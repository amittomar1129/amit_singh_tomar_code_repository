                               Sorting Techniques


Basic O(n²): Used for learning, small inputs, or interviews to test fundamentals. Easy, but not scalable.
Bubble Sort
Selection Sort
Insertion Sort

Efficient (O(n log n)):
Merge Sort
Quick Sort
Heap Sort

Non-Comparison Sorting (Very Powerful) O(n): These do NOT compare elements directly. Used when data has constraints.
Counting Sort
Radix Sort
Bucket Sort

Used in real systems:
Tim Sort (Python, Java) best: O(n) worst:


Stable Algorithms: Preserve order of equal elements.
In-Place Algorithms: Modifies the input array to construct the output. Do not use extra space.

In-Place:
Bubble Sort
Selection Sort
Insertion Sort
Quick Sort
Heap Sort

Not In-Place:
Merge Sort
TimSort
Counting Sort
Radix Sort
Bucket Sort

Stable:
Bubble Sort
Insertion Sort
Merge Sort
TimSort
Counting Sort
Radix Sort
Bucket Sort (Stable if each bucket uses stable sort)

Unstable:
Selection Sort
Quick Sort
Heap Sort
